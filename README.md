# هتصلي يعني هتصلي 🕌 - منبه الفجر الذكي

تطبيق ويب + **تطبيق أندرويد أصلي (APK حقيقي)** بنفس الكود.

> تم تصميم هذا البرنامج لإيقاظك لصلاة الفجر وجميع الصلوات فلا تنسانا من صالح دعائكم 🤍

## زر التحميل 📥

عند الضغط على زر **"تحميل / ثبّت الآن"** في الموقع:

1. يتحقق من آخر نسخة APK مبنية (`/downloads/apk-info.json`)
2. يحمّل ملف **`hatsally.apk` الحقيقي** على الهاتف مع نسبة تقدم %
3. يعرض خطوات التثبيت: افتح الملف ← اسمح بالتثبيت ← ثبّت وافتح 🕌
4. إن لم تكن النسخة جاهزة بعد، يجرّب رابط GitHub Releases تلقائياً

## لماذا يرنّ المنبه الآن حتى لو أغلقت التطبيق؟ 🛡

المشكلة القديمة: الاعتماد على تنبيهات Capacitor المحلية + مؤقّت داخل صفحة الويب.
لو أُغلق التطبيق أو قتله النظام (شاومي/سامسونج/هواوي) ضاع الموعد بصمت.

الحل الجديد: **محرك منبه أصلي كامل داخل الأندرويد** لا يعتمد على الـ WebView إطلاقاً:

```
اضغط «اضبط المنبه»
   ↓
AlarmStore (SharedPreferences)      ← الإعدادات محفوظة في النظام الأصلي
   ↓
AlarmScheduler → AlarmManager.setAlarmClock()   ← أدق منبه في أندرويد (يوقظ من Doze)
   ↓
AlarmGuardService (خدمة أمامية)      ← تُبقي التطبيق حياً بعد إغلاقه
   │    └─ إشعار مثبت لا يمكن إزالته (يعود فوراً + يُعاد نشره كل 20 ثانية)
   ↓ عند حلول الموعد
AlarmReceiver → AlarmRinger          ← صوت منبه متواصل بأقصى صوت + اهتزاز
   │                                   + نداء باسمك (TTS) + إيقاظ الشاشة فوق القفل
   └─ إشعار بملء الشاشة يفتح التطبيق ← التحقق بالتصوير (صنبور + مصلاة + وجه)
   ↓
إعادة جدولة الموعد القادم + BootReceiver بعد إعادة تشغيل الهاتف
```

| الملف | الدور |
|---|---|
| `AlarmStore.java` | حفظ المنبه في إعدادات أندرويد الأصلية (لا في localStorage فقط) |
| `AlarmScheduler.java` | حساب الموعد القادم (مطابق 100% لـ `lib/schedule.ts`) + `setAlarmClock` + اللحاق بالموعد الفائت |
| `AlarmGuardService.java` | الخدمة الأمامية: الإشعار المثبت + النبض الدوري + الشفاء الذاتي لو ضاعت الجدولة |
| `AlarmRinger.java` | الرنين الأصلي: صوت/اهتزاز/نداء بالاسم/إيقاظ الشاشة/تجاوز عدم الإزعاج |
| `AlarmReceiver.java` | استقبال الموعد + إعادة الإشعار المثبت لو مُسح |
| `BootReceiver.java` | إعادة البناء بعد الإقلاع/تغيير الوقت/المنطقة الزمنية/تحديث التطبيق |
| `AlarmPowerPlugin.java` | الجسر بين الواجهة والمحرك (`setAlarm`, `syncNow`, `getState`, `testRing`…) |
| `lib/alarmPower.ts` | تعريف الإضافة الأصلية في TypeScript |

### ضمانات إضافية

- **START_STICKY + onTaskRemoved**: تعود الخدمة تلقائياً بعد القتل أو إغلاق التطبيق من التطبيقات الأخيرة.
- **فحص دوري كل 20 ثانية** داخل الخدمة: لو ضاع المنبه من النظام يُعاد جدولته، ولو فات الموعد ضمن المهلة يرنّ فوراً (catch-up).
- **رنين أصلي مستقل**: الصوت والاهتزاز والنداء بالاسم تعمل من الخدمة مباشرة، فلو تأخر الـ WebView أو مات فالهاتف يظل يرنّ.
- **اختبارات**: `npm run test:alarm` (محرك الويب) + `cd android && ./gradlew testDebugUnitTest` (المحرك الأصلي) بنفس الحالات تماماً.

## لو لم يرنّ المنبه - checklist 🔎

1. افتح التطبيق → بطاقة **«🛡 الحارس الأصلي»**: يجب أن تكون `ON`.
2. في نفس البطاقة تأكد من ✓ على: **منبه دقيق**، **بطارية**، **إشعارات**، **شاشة كاملة** (اضغط أي ✗ لمنح الإذن).
3. اضغط **«اختبر الرنين الحقيقي بعد 20 ثانية»** - إن قرع الهاتف فالمحرك سليم 100%.
4. هواتف شاومي/أوبو/فيفو/هواوي:Settings → Battery → *No restrictions* للتطبيق + فعّل «التشغيل التلقائي/Autostart».
5. لا تستخدم «إيقاف إجباري/Force stop» من إعدادات التطبيق - أندرويد يلغي كل المنبهات عندها (إغلاق التطبيق من التطبيقات الأخيرة آمن لأن الحارس يعمل).

## كيف يُبنى ملف APK؟ 🤖

البناء يتم **تلقائياً** عبر GitHub Actions عند كل دفع على `main`:

```
الكود (Next.js) → تصدير ثابت out/ → Capacitor → Gradle → hatsally.apk
```

ملف السير: [`.github/workflows/build-apk.yml`](.github/workflows/build-apk.yml)

بعد البناء يُرفع الملف في 3 أماكن:

1. `public/downloads/hatsally.apk` (يُحدّث تلقائياً في المستودع - زر الموقع يحمّل منه)
2. [GitHub Release `apk-latest`](https://github.com/y5747m-gif/moslm-we-bas-/releases/latest/download/hatsally.apk) (رابط ثابت بديل)
3. Artifacts صفحة الـ Actions (لمدة 30 يوم)

## التشغيل محلياً 💻

```bash
npm install
npm run dev        # موقع الويب
npm run build      # بناء الويب للإنتاج
```

## بناء نسخة الأندرويد محلياً (يحتاج Android SDK مع API 36 + JDK 21)

```bash
npm run build:apk      # تصدير ثابت + مزامنة Capacitor
npm run apk:assemble   # بناء hatsally.apk عبر Gradle
```

## محرك التحقق البصري 🔍

تحقق حقيقي من صور الإثبات الثلاث (بدون تخمين ولا عشوائية):

| المهمة | الفحوصات |
|---|---|
| 🚰 صنبور المياه | معدن بارز + بصمة الكروم اللونية + شكل أنبوبي + لمعة + سياق مغسلة (اللقطة البعيدة تُرفض ويُطلب الاقتراب) |
| 🕌 المصلاة | تناظر مقاوم للمنظور + ألوان سجاد عميقة + نسيج وزخارف + إطار الحدود |
| 👁️ الوجه | شبكة عصبية (TinyFaceDetector + 68 معلماً) تتأكد أنه **وجه بشري** وأن **العينين مفتوحتان** عبر نسبة EAR |

- النماذج مضمّنة في التطبيق (`public/models` - 284KB) وتعمل **بدون إنترنت**
- كل فحص يعرض ✓/✗ مع نصيحة مصورة لإعادة التصوير
- عتبة تكيفية: تشتد أولاً ثم تتساهل تدريجياً مع المحاولات (بحد أدنى)
- اختبار الانحدار: `npm run test:vision` (11/11 على صور حقيقية + صور سلبية)
