# هتصلي يعني هتصلي 🕌 - منبه الفجر الذكي

تطبيق ويب + **تطبيق أندرويد أصلي (APK حقيقي)** بنفس الكود.

> تم تصميم هذا البرنامج لإيقاظك لصلاة الفجر وجميع الصلوات فلا تنسانا من صالح دعائكم 🤍

## زر التحميل 📥

عند الضغط على زر **"تحميل / ثبّت الآن"** في الموقع:

1. يتحقق من آخر نسخة APK مبنية (`/downloads/apk-info.json`)
2. يحمّل ملف **`hatsally.apk` الحقيقي** على الهاتف مع نسبة تقدم %
3. يعرض خطوات التثبيت: افتح الملف ← اسمح بالتثبيت ← ثبّت وافتح 🕌
4. إن لم تكن النسخة جاهزة بعد، يجرّب رابط GitHub Releases تلقائياً

## مواصفات التطبيق الكاملة ✨

| المواصفة | التفاصيل |
|---|---|
| 📢 يناديك باسمك | صوت رجل عميق - Web Speech في المتصفح + محرك الهاتف TTS داخل APK |
| 😤 تصعيد تدريجي | نداء لطيف ← جرس مزعج ← كابوس لا يُحتمل |

| 🤖 ذكاء اصطناعي حقيقي | رؤية حاسوبية للصنبور/المصلاة + شبكة عصبية للوجه والعينين (بدون إنترنت) |
| 📴 يعمل بدون إنترنت | PWA + Service Worker + تنبيهات أصلية داخل APK حتى لو مغلق |
| 🔒 لا يمكن إغلاقه | منع إغلاق الصفحة/الرجوع أثناء الرنين + تنبيه دائم |
| 🔊 فرض الاستيقاظ | صوت أقصى + إيقاظ الشاشة فوق القفل أثناء الرنين ثم إرجاع كل شيء (إضافة AlarmPower الأصلية) |
| 🔐 أذونات المستخدم | المستخدم يمنح الموافقات بنفسه: إشعارات + كاميرا + منبه دقيق + بطارية + عدم إزعاج - لا منبه بدونها |
| 📲 الموقع يثبّت التطبيق | تحميل APK مباشر + QR حقيقي + فتح التطبيق المثبت من المتصفح (hatsally://) |
| 🌍 لغتان | العربية (RTL) والإنجليزية |
| 🌗 مظهران | داكن وفاتح |
| 📅 أيام التكرار | اختيار أيام عمل المنبه |
| ⏳ مدة المنبه | دائم أو 7 / 14 / 30 يوم أو مخصص |
| ⏱ رنين دقيق مضمون | محرك جدولة (lib/schedule.ts) يرنّ عند حلول الموعد أو بعده بمهلة 45 دقيقة + عدّاد حي للرنين القادم + اللحاق عند فتح التطبيق أو الضغط على التنبيه |

## كيف يُبنى ملف APK؟ 🤖

البناء يتم **تلقائياً** عبر GitHub Actions عند كل دفع على `main`:

```
الكود (Next.js) → تصدير ثابت out/ → Capacitor → Gradle → hatsally.apk
```

ملف السير: [`.github/workflows/build-apk.yml`](.github/workflows/build-apk.yml)

بعد البناء يُرفع الملف في 3 أماكن:

1. `public/downloads/hatsally.apk` (يُحدّث تلقائياً في المستودع - زر الموقع يحمّل منه)
2. [GitHub Release `apk-latest`](https://github.com/y5747m-gif/moslm-we-bas-/releases/latest/download/hatsally.apk) (رابط ثابت بديل)
3. Artifacts صفحة الـ Actions (لمدة 30 يوم)

## التشغيل محلياً 💻

```bash
npm install
npm run dev        # موقع الويب
npm run build      # بناء الويب للإنتاج
```

## بناء نسخة الأندرويد محلياً (يحتاج Android SDK مع API 36 + JDK 21)

```bash
npm run build:apk      # تصدير ثابت + مزامنة Capacitor
npm run apk:assemble   # بناء hatsally.apk عبر Gradle
```

## محرك التحقق البصري 🔍

تحقق حقيقي من صور الإثبات الثلاث (بدون تخمين ولا عشوائية):

| المهمة | الفحوصات |
|---|---|
| 🚰 صنبور المياه | معدن بارز + بصمة الكروم اللونية + شكل أنبوبي + لمعة + سياق مغسلة (اللقطة البعيدة تُرفض ويُطلب الاقتراب) |
| 🕌 المصلاة | تناظر مقاوم للمنظور + ألوان سجاد عميقة + نسيج وزخارف + إطار الحدود |
| 👁️ الوجه | شبكة عصبية (TinyFaceDetector + 68 معلماً) تتأكد أنه **وجه بشري** وأن **العينين مفتوحتان** عبر نسبة EAR |

- النماذج مضمّنة في التطبيق (`public/models` - 284KB) وتعمل **بدون إنترنت**
- كل فحص يعرض ✓/✗ مع نصيحة مصورة لإعادة التصوير
- عتبة تكيفية: تشتد أولاً ثم تتساهل تدريجياً مع المحاولات (بحد أدنى)
- اختبار الانحدار: `npm run test:vision` (11/11 على صور حقيقية + صور سلبية)

## التثبيت على الهاتف 📱

1. افتح الموقع على هاتفك الأندرويد
2. اضغط زر التحميل ← سيُنزّل `hatsally.apk`
3. افتح الملف من التنزيلات
4. اسمح بـ **"التثبيت من مصادر غير معروفة"** إذا طُلب منك
5. اضغط **تثبيت** ثم افتح التطبيق واضبط منبهك ⏰
