# 🕌 إيقاظ الفجر — Iqaz Alfajr

تطبيق أندرويد مجاني **يوقظ المستخدم يوميًا لصلاة الفجر**، و**موقع ويب** يستضيف ملف APK لتنزيله مباشرة على الهاتف.

## الفلسفة

- **الإيقاظ الحقيقي**: صوت يرنّ بلا توقف + اهتزاز + شاشة كاملة تُشغَّل فوق القفل، ولا يصمت المنبه إلا بضغطة المستخدم من شاشة المنبه (لا زر صدّاد في الإشعار).
- **الموافقات بيد المستخدم**: لا يطلب التطبيق أي إذن وقت التثبيت؛ بل بطاقة «الصلاحيات» داخل التطبيق تعرض كل إذن ويمنحه المستخدم بضغطة (الإشعارات، فوق شاشة القفل، تجاهل تحسين البطارية، الموقع الاختياري).
- **بلا إنترنت**: مواقيت الفجر تُحسب فلكيًا داخل الهاتف (خوارزمية PrayTimes) — صفر اتصالات شبكة، صفر تتبع.
- **الويب يوزّع التطبيق**: مستودع GitHub يبني الـ APK تلقائيًا ويدفعه إلى `public/apk/iqaz-alfajr.apk`، فيستضيفه موقع Next.js مع رمز QR للمسح بكاميرا الهاتف.

## البنية

```
├── android/                    # تطبيق أندرويد (Java، بلا تبعيات خارجية)
│   └── app/src/main/
│       ├── java/com/fajr/wake/
│       │   ├── MainActivity.java    # الشاشة الرئيسية (تفعيل/أذونات/إعدادات)
│       │   ├── AlarmActivity.java   # شاشة المنبه فوق القفل (إيقاف/غفوة)
│       │   ├── AlarmService.java    # مشغّل الصوت/الاهتزاز حتى يقظة المستخدم
│       │   ├── AlarmReceiver.java   # استقبال رنّات المنبه
│       │   ├── RescheduleReceiver.java # إعادة الجدولة بعد الإقلاع/تغيير الوقت
│       │   ├── PrayerTimes.java     # الحساب الفلكي لوقت الفجر
│       │   ├── Prefs.java           # الإعدادات + قوائم المدن والطرق
│       │   └── AlarmTools.java      # جدولة setAlarmClock والإشعارات
│       └── res/                    # نصوص عربية، أيقونات، ألوان
├── src/app/                    # موقع Next.js (عربي RTL) يستضيف الـ APK
├── public/apk/                 # ← يوضع هنا ملف iqaz-alfajr.apk بعد البناء
└── .github/workflows/build-apk.yml  # يبني الـ APK ويدفعه للموقع تلقائيًا
```

## آلية التوزيع (الويب يحمل الـ APK)

1. أي `git push` إلى `main` أو `arena/**` يشغّل **Build APK 📱** على GitHub Actions.
2. الـ Workflow يبني `assembleRelease` ويوقّع التطبيق بمفتاح ثابت (`android/keystore/fajr.keystore` — يُنشأ ويُخزَّن في المستودع أول مرة).
3. يُنسخ الملف إلى `public/apk/iqaz-alfajr.apk` ويُدفع إلى الفرع تلقائيًا.
4. موقع Next.js يعرض صفحة تنزيل + QR؛ رابط الملف المباشر: `/apk/iqaz-alfajr.apk`.

## مميزات التطبيق

- ⏰ `AlarmManager.setAlarmClock` — أكثر الطرق موثوقية وأقلها تأثرًا بوضع الاستعداد (Doze).
- 🔒 شاشة كاملة فوق القفل مع `USE_FULL_SCREEN_INTENT` و`showWhenLocked`.
- 🔊 أذان من ملف الهاتف (`ACTION_OPEN_DOCUMENT` + إذن دائم) أو النغمة الافتراضية أو اهتزاز فقط.
- 🔁 منبه احتياطي بعد ١٠ دقائق + غفوة بحد أقصى ٣ مرات (٥ دقائق لكل غفوة).
- 🌍 ٤٠ مدينة عربية/إسلامية جاهزة أو تحديد GPS، و٥ طرق حساب (أم القرى، رابطة العالم، المصري، ISNA، كراتشي).
- 🕌 تنبيه قبل الأذان بصفر/٥/١٠/١٥/٢٠/٣٠ دقيقة (اختياري).
- ☀️ خطة بديلة لصيف خطوط العرض العالية (سُدس الليل) حين لا تبلغ الشمس زاوية الفجر.
- 📴 يعيد الضبط تلقائيًا بعد إعادة التشغيل أو تغيير الوقت/المنطقة أو تحديث التطبيق، ويعوّض إن فات المنبه.

## التطوير المحلي

```bash
npm install
npm run dev        # موقع الويب على http://localhost:3000
npm run build      # بناء الموقع

# بناء الأندرويد (يتطلب JDK 17 وAndroid SDK 34):
gradle -p android assembleRelease
# الناتج: android/app/build/outputs/apk/release/app-release.apk
```

## متطلبات الهاتف

- أندرويد 8.0 (API 26) فأحدث.
- التثبيت من «مصادر غير معروفة» مرة واحدة عند أول تنزيل.
