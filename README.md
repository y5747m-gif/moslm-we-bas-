# هتصلي يعني هتصلي 🕌 - تطبيق المنبهات الذكية

**تطبيق مستقل بهويته الخاصة** (شريط علوي + تبويبات سفلية + ألواح سفلية + شاشة بداية) وليس صفحة ويب،
يعمل كـ PWA وكتطبيق **أندرويد أصلي (APK حقيقي)** من نفس الكود.

> تم تصميم هذا البرنامج لإيقاظك لصلاة الفجر وجميع الصلوات فلا تنسانا من صالح دعائكم 🤍

## الجديد في هذه النسخة 🆕

| الميزة | التفاصيل |
|---|---|
| ⏰ **منبهات متعددة بلا حد** | أضف منبهاً لكل صلاة أو موعد: لكل منبه اسمه ووقته وتكراره ومدته وتفعيله المستقل (زر ➕ أو اختصار "منبه جديد") |
| 🔁 **رنين في نفس الموعد كل يوم** | التكرار الافتراضي **كل يوم**: الوقت الذي تضبطه يرن في نفس الساعة يومياً بدون إعادة ضبط، حتى بعد الرنين أو إكمال التحقق |
| 📱 **هوية تطبيق مستقلة** | تنقّل بتبويبات سفلية (المنبهات / التحقق / الإعدادات / حول)، بطاقات ومفاتيح أصلية، لوح سفلي للإضافة والتعديل، شاشة بداية، وإطار جهاز على الحاسوب - بنفس كل المميزات المطلوبة |
| 👨‍💻 **اسم المطور** | في آخر التطبيق (شاشة **حول**): `Yaseen amr abd el rahem` |

## شاشات التطبيق 📱

```
┌─────────────────────────────┐
│ 🌙 هتصلي       05:12   ع  🌙 │  ← شريط التطبيق (لغة/مظهر/ساعة)
│ 1/3 منبه • offline • كل يوم │  ← شريط الحالة
├─────────────────────────────┤
│  منبهاتي                     │
│  ┌─ الرنين القادم ─────────┐ │
│  │ 04:40  الفجر • كل يوم   │ │
│  │ يرن بعد 22 س 28 د       │ │
│  └─────────────────────────┘ │
│  ┌─ 04:40  [الفجر] كل يوم  ◉┐│  ← بطاقة منبه (تفعيل/تجربة/تعديل/حذف)
│  └───────────────────────────┘│
│  ┌─ 12:15  [الظهر] أيام عمل ◉┐│
│  └───────────────────────────┘│
│                          (➕) │  ← إضافة منبه جديد
├─────────────────────────────┤
│ المنبهات | التحقق | الإعدادات | حول │  ← تبويبات سفلية
└─────────────────────────────┘
```

- **المنبهات**: القائمة + العدّاد الحي للرنين القادم + زر الإضافة العائم.
- **التحقق**: شرح مهام الإثبات الثلاث (صنبور/مصلاة/وجه) ومراحل التصعيد + زر تجربة الرنين.
- **الإعدادات**: الاسم، اللغة، المظهر، وضع التجربة السريعة، الكتم، الأذونات، التثبيت (PWA/APK)، الإصدار.
- **حول**: هوية التطبيق والمميزات والدعاء، وفي الآخر **اسم المطور**.
- **شاشة الرنين**: تملأ التطبيق فوق كل التبويبات، تتصاعد (نداء ← جرس ← كابوس)، غفوة واحدة بالضغط المطول،
  ثم تحقق بالتصوير لا يُغلق إلا بإكماله.

## مواصفات التطبيق الكاملة ✨

| المواصفة | التفاصيل |
|---|---|
| ⏰ منبهات متعددة | أي عدد من المنبهات، لكل واحد وقت واسم وتكرار ومدة وتفعيل مستقل |
| 🔁 تكرار يومي مضمون | كل منبه يرن في نفس الموعد كل يوم (مرة واحدة في اليوم) ويعود غداً تلقائياً |
| 📢 يناديك باسمك | صوت رجل عميق - Web Speech في المتصفح + محرك الهاتف TTS داخل APK |
| 😤 تصعيد تدريجي | نداء لطيف ← جرس مزعج (5 د) ← كابوس لا يُحتمل (10 د) |
| 📷 تحقق بالتصوير | صنبور المياه (الوضوء) + المصلاة + الوجه والعينان مفتوحتان |
| 🤖 ذكاء اصطناعي حقيقي | رؤية حاسوبية للصنبور/المصلاة + شبكة عصبية للوجه والعينين (بدون إنترنت) |
| 📴 يعمل بدون إنترنت | PWA + Service Worker + تنبيهات أصلية داخل APK حتى لو مغلق |
| 🔒 لا يمكن إغلاقه | منع إغلاق الصفحة/الرجوع أثناء الرنين + إشعار دائم يعود إن حُذف |
| 🔊 فرض الاستيقاظ | صوت أقصى + إيقاظ الشاشة فوق القفل أثناء الرنين ثم إرجاع كل شيء (إضافة AlarmPower الأصلية) |
| 🔐 أذونات المستخدم | المستخدم يمنح الموافقات بنفسه: إشعارات + كاميرا + منبه دقيق + بطارية + عدم إزعاج - لا تفعيل بدونها |
| 📲 الموقع يثبّت التطبيق | تحميل APK مباشر + QR حقيقي + فتح التطبيق المثبت من المتصفح (hatsally://) |
| 🌍 لغتان | العربية (RTL) والإنجليزية |
| 🌗 مظهران | داكن وفاتح |
| 📅 أيام التكرار | كل يوم (افتراضي) أو أيام محددة أو أيام العمل أو العطلة |
| ⏳ مدة المنبه | دائم أو 7 / 14 / 30 يوم أو مخصص (يُوقف تلقائياً عند انتهائه) |
| ⏱ رنين دقيق مضمون | محرك جدولة (`lib/schedule.ts` + `lib/alarms.ts`) يرنّ عند الموعد أو بعده بمهلة 45 دقيقة، مع عدّاد حي ولحاق عند فتح التطبيق أو الضغط على التنبيه |

## كيف يعمل الرنين اليومي؟ 🔁

1. عند الحفظ يُدفع كل منبه إلى **Service Worker** (IndexedDB) وإلى **تنبيهات أندرويد الأصلية**
   كتنبيه متكرر لكل يوم مختار (`on: {hour, minute, weekday}, repeats: true`).
2. يفحص المحرك كل ثانية (وكل 30 ثانية داخل الـ SW) كل منبه مفعّل:
   - لم يحن وقته ← انتظار
   - حان وقته (أو فات ضمن 45 دقيقة) ولم يرنّ اليوم ← **رنين** + تعليم اليوم
   - فات أكثر من المهلة ← يُعلَّم اليوم بصمت (لا إزعاج متأخر)
   - انتهت مدته ← يُوقف تلقائياً
3. بعد الرنين وإكمال التحقق **يبقى المنبه مفعّلاً** ويرن غداً في نفس الموعد - لا يحتاج إعادة ضبط.
4. إن استحق أكثر من منبه في اللحظة نفسها يرنّ الأبكر، وتُعلَّم البقية معها (استيقاظ واحد يكفي).

## زر التحميل 📥

عند الضغط على **التثبيت / تحميل APK** داخل التطبيق:

1. يتحقق من آخر نسخة APK مبنية (`/downloads/apk-info.json`)
2. يحمّل ملف **`hatsally.apk` الحقيقي** على الهاتف مع نسبة تقدم %
3. يعرض خطوات التثبيت: افتح الملف ← اسمح بالتثبيت ← ثبّت وافتح 🕌
4. إن لم تكن النسخة جاهزة بعد، يجرّب رابط GitHub Releases تلقائياً

## كيف يُبنى ملف APK؟ 🤖

البناء يتم **تلقائياً** عبر GitHub Actions عند كل دفع:

```
الكود (Next.js) → تصدير ثابت out/ → Capacitor → Gradle → hatsally.apk
```

ملف السير: [`.github/workflows/build-apk.yml`](.github/workflows/build-apk.yml)

بعد البناء يُرفع الملف في 3 أماكن:

1. `public/downloads/hatsally.apk` (يُحدّث تلقائياً في المستودع - زر التطبيق يحمّل منه)
2. [GitHub Release `apk-latest`](https://github.com/y5747m-gif/moslm-we-bas-/releases/latest/download/hatsally.apk) (رابط ثابت بديل)
3. Artifacts صفحة الـ Actions (لمدة 30 يوم)

## التشغيل محلياً 💻

```bash
npm install
```

## بناء نسخة الأندرويد محلياً (يحتاج Android SDK مع API 36 + JDK 21)

```bash
npm run build:apk      # تصدير ثابت + مزامنة Capacitor
npm run apk:assemble   # بناء hatsally.apk عبر Gradle
```

## محرك التحقق البصري 🔍

تحقق حقيقي من صور الإثبات الثلاث (بدون تخمين ولا عشوائية):

| المهمة | الفحوصات |
|---|---|
| 🚰 صنبور المياه | معدن بارز + بصمة الكروم اللونية + شكل أنبوبي + لمعة + سياق مغسلة (اللقطة البعيدة تُرفض ويُطلب الاقتراب) |
| 🕌 المصلاة | تناظر مقاوم للمنظور + ألوان سجاد عميقة + نسيج وزخارف + إطار الحدود |
| 👁️ الوجه | شبكة عصبية (TinyFaceDetector + 68 معلماً) تتأكد أنه **وجه بشري** وأن **العينين مفتوحتان** عبر نسبة EAR |

- النماذج مضمّنة في التطبيق (`public/models` - 284KB) وتعمل **بدون إنترنت**
- كل فحص يعرض ✓/✗ مع نصيحة مصورة لإعادة التصوير
- عتبة تكيفية: تشتد أولاً ثم تتساهل تدريجياً مع المحاولات (بحد أدنى)

## التثبيت على الهاتف 📱

1. افتح التطبيق/الموقع على هاتفك الأندرويد
2. من **الإعدادات ← التثبيت**: اضغط تحميل APK (أو تثبيت سريع من المتصفح)
3. افتح الملف من التنزيلات واسمح بـ **"التثبيت من مصادر غير معروفة"** إذا طُلب
4. اضغط **تثبيت** ثم افتح التطبيق
5. امنح الأذونات، ثم اضغط ➕ وأضف منبهاتك - كل منبه يرن في موعده **كل يوم** ⏰
