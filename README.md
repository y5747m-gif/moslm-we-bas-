# 🌙 منبه الفجر | Fajr Alarm

تطبيق أندرويد + موقع تحميل: **منبه قوي لصلاة الفجر لا يتوقف إلا بعد التقاط 3 صور بالكاميرا**
لإثبات الاستيقاظ — بموافقة المستخدم الكاملة.

## المكونات

| المجلد | الوظيفة |
|---|---|
| `src/app` | موقع الويب (Next.js) — شرح + تحميل ملف APK |
| `android/` | تطبيق الأندرويد الأصلي (Kotlin + CameraX) |
| `.github/workflows` | بناء تلقائي للـ APK عند كل تحديث |

## فكرة التطبيق

1. المستخدم يثبّت التطبيق **بإرادته** ويمنح الأذونات **بنفسه**.
2. يضبط موعد الفجر ويُفعّل المنبه.
3. عند الموعد: رنين عالٍ + اهتزاز + شاشة كاملة فوق القفل.
4. لا يتوقف إلا بعد **3 صور** بالكاميرا (عدّاد 1/3 ← 3/3).
5. مخارج مشروعة دائماً: **غفوة 5 دقائق** + **إيقاف طوارئ (ضغط مطوّل 5 ثوانٍ)** + **إيقاف تلقائي بعد 15 دقيقة**.

## الأذونات (بشفافية)

| الإذن | السبب |
|---|---|
| `CAMERA` | التقاط صور إثبات الاستيقاظ أثناء الرنين فقط |
| `POST_NOTIFICATIONS` | تنبيه الرنين فوق القفل مع الصوت والاهتزاز |
| `SCHEDULE_EXACT_ALARM` | الرنين في الموعد الدقيق |
| `RECEIVE_BOOT_COMPLETED` | إعادة الجدولة بعد إعادة التشغيل (إذا كان مفعّلاً) |
| `FOREGROUND_SERVICE` | صوت الرنين الموثوق |

**لا يوجد**: إذن إنترنت (الصور لا تغادر الجهاز)، ولا قراءة للإشعارات، ولا موقع، ولا جهات اتصال.

## بناء الـ APK

تلقائياً عبر GitHub Actions (`.github/workflows/build-apk.yml`):
- أي Push على `main` يمس `android/` يبني APK ويرفعه كـ Artifact.
- لعمل إصدار رسمي: شغّل الـ Workflow يدوياً مع `release_tag` مثل `v1.0.0` —
  سيُنشئ Release ويُرفق `fajr-alarm.apk`، وسيظهر تلقائياً في موقع التحميل.

محلياً (تحتاج JDK 17 + Android SDK):

```bash
cd android
gradle :app:assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```

## تشغيل الموقع

```bash
npm install
npm run dev
# http://localhost:3000
```
