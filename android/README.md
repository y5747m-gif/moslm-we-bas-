# تطبيق منبه الفجر (أندرويد أصلي)

Kotlin + CameraX — يعمل من أندرويد 8.0 (API 26) فأحدث، وبدون إنترنت تماماً.

## البنية

```
app/src/main/java/com/fajrwake/alarm/
├── MainActivity.kt          # الإعدادات: الموعد + التفعيل + الأذونات + اختبار + الصور
├── AlarmActivity.kt         # شاشة الرنين فوق القفل + تحدي الصور الثلاث
├── AlarmForegroundService.kt# خدمة الرنين (صوت + اهتزاز + إشعار مستمر + أمان 15 دقيقة)
├── AlarmScheduler.kt        # جدولة دقيقة عبر setAlarmClock (يومية + غفوة + اختبار)
├── AlarmReceiver.kt         # يستقبل موعد الرنين ويشغّل الخدمة ويجدول الغد
├── SnoozeReceiver.kt        # الغفوة الصادقة: إيقاف + رنين بعد 5 دقائق
├── BootReceiver.kt          # إعادة الجدولة بعد الإقلاع (إذا كان مفعّلاً فقط)
├── PhotoCaptureManager.kt   # التقاط CameraX قوي: إعادة محاولة + تحقق + كاميرا أمامية/خلفية
├── SoundPlayer.kt           # نغمة منبه الجهاز + اهتزاز متكرر
├── PermissionHelper.kt      # فحوصات الأذونات وروابط شاشات النظام
└── AlarmStore.kt            # حفظ الإعدادات محلياً فقط
```

## سلوك الإغلاق (المتفق عليه مع المستخدم)

- زر الرجوع والإيماءات **لا** تغلق شاشة الرنين (مع رسالة توضح البدائل).
- الإغلاق يتم فقط عبر: **إكمال 3 صور** ✓، أو **الغفوة**، أو **الطوارئ (5 ثوانٍ ضغط)**،
  أو **التوقف التلقائي بعد 15 دقيقة** — والحذف من النظام يعمل دائماً.
